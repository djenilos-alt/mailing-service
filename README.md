# Mailing Service

Веб-приложение на Django для управления email-рассылками.

## Возможности

-   Регистрация пользователей с подтверждением адреса электронной почты.
-   Авторизация и восстановление пароля.
-   Управление получателями рассылок: создание, просмотр, редактирование
    и удаление.
-   Управление сообщениями: тема и текст письма.
-   Создание и управление рассылками.
-   Автоматическое определение статуса рассылки по времени:
    -   **Создана** --- время начала ещё не наступило.
    -   **Запущена** --- текущее время находится в интервале рассылки.
    -   **Завершена** --- время окончания прошло.
-   Ручной запуск рассылки в допустимый временной интервал.
-   Сохранение результатов отправки для каждого получателя.
-   Статистика успешных и неуспешных попыток отправки.
-   Разграничение доступа: обычный пользователь работает со своими
    данными, менеджер имеет доступ к общему списку рассылок и
    получателей и может блокировать пользователей и отключать рассылки.
-   Кэширование отдельных статистических данных и приватное кэширование
    ответов.

## Установка и запуск

### 1. Клонирование репозитория

``` bash
git clone https://github.com/djenilos-alt/mailing-service.git
cd mailing-service
```

### 2. Установка зависимостей

``` bash
poetry install
```

### 3. Настройка переменных окружения

В корневой папке проекта создайте файл `.env`.

Сгенерируйте секретный ключ Django:

``` bash
poetry run python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Добавьте в `.env` полученное значение:

``` dotenv
SECRET_KEY=вставьте_сюда_сгенерированный_ключ
```

Не публикуйте `.env` и не добавляйте секретный ключ в репозиторий. Файл
`.env` уже включён в `.gitignore`.

### 4. Применение миграций

``` bash
poetry run python manage.py migrate
```

### 5. Создание администратора

``` bash
poetry run python manage.py createsuperuser
```

Следуйте инструкциям в терминале.

### 6. Запуск сервера разработки

``` bash
poetry run python manage.py runserver
```

Откройте в браузере:

-   Главная страница: http://127.0.0.1:8000/
-   Панель администратора: http://127.0.0.1:8000/admin/

## Отправка писем

В текущей конфигурации используется консольный email backend Django.
Сформированные письма выводятся в терминал, в котором запущен сервер, а
не доставляются реальным адресатам.

Для реальной отправки писем необходимо настроить подходящий почтовый
backend и его параметры в `config/settings.py`, используя безопасное
хранение учётных данных в переменных окружения.

## Тестирование

Запуск всех тестов проекта:

``` bash
poetry run python manage.py test
```

Проверка конфигурации Django:

``` bash
poetry run python manage.py check
```

Проверка отсутствия изменений в миграциях:

``` bash
poetry run python manage.py makemigrations --check --dry-run
```

## Структура проекта

``` text

├── config/       # Настройки проекта и корневые URL-маршруты Django
├── mailing/      # Получатели, сообщения, рассылки и попытки отправки

└── .gitignore
```

## Примечание

Проект предназначен для учебной демонстрации управления рассылками.
Перед использованием в production необходимо отдельно настроить реальный
почтовый сервис, параметры безопасности Django, допустимые хосты, HTTPS
и соответствующую инфраструктуру.
